# 🎭 Mad Libs Game

A simple and fun Python project that creates a hilarious story based on user-provided words. Every time you enter different words, the story becomes unique and entertaining.

## ✨ Features

* Beginner-friendly Python project
* Interactive command-line interface
* Generates a different story with every play
* Uses Python variables, user input, and f-strings
* Great for practicing basic Python concepts

## 📝 User Inputs

The game asks the user to enter:

* Adjective
* Place
* Animal
* Verb (ending with **-ing**)
* Food

## ▶️ How to Run

1. Make sure **Python 3** is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in **VS Code** or your terminal.
4. Run the program:

```bash
Madlibs Game.py
```

5. Enter the requested words.
6. Enjoy your funny Mad Libs story!

## 📖 Example

### Input

```text
Adjective: beautiful
Place: park
Animal: panda
Verb (-ing): dancing
Food: pizza
```

### Output

```text
Yesterday, I visited a beautiful park.
Out of nowhere, a giant panda appeared.
It started dancing, and everyone was completely shocked.
I was nervous, but I stayed calm.
The panda only wanted to share my pizza.
We enjoyed the pizza together and became best friends!
Everyone cheered and took lots of pictures.
It turned out to be the funniest day of my life!
```
